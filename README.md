# LainTheme-xfce
cool full config and setup theme, icon, .... on xfce (for debian based)


# Installation 
### Download 
```
sudo apt update
sudo apt install git

git clone https://github.com/mr-r0ot/LainTheme-xfce.git
```

### Step1 (required)
**Note:** if you see something strange in UI don't panic, everything going to be fixed in step 2 
```
cd LainTheme-xfce

chmod +x step1.sh
./step1.sh
# it's better have reboot here!

```

### Step2 (required)
**Note:** exist two version **step2_lite.sh** for week systems (if you have a little ram or a week gpu/cpu use lite) and a **step2_high.sh** (High version have glass window, background and theme + animations)

```
chmod +x step2_lite.sh
./step2_lite.sh

or

chmod +x step2_high.sh
./step2_high.sh

sudo reboot now
```
